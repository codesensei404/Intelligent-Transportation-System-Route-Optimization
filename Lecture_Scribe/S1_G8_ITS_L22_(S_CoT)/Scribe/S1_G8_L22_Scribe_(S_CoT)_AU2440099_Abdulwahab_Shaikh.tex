\section*{1. Motivation: Tail Bounds}

\subsection*{Key Idea}

\begin{itemize}
    \item The lecture begins with \textbf{tail bounds}, which are used to:
    \begin{itemize}
        \item Estimate \textbf{probabilities of extreme events}
        \item Understand \textbf{worst-case behavior}
    \end{itemize}
\end{itemize}

\subsection*{Interpretation}

\begin{itemize}
    \item The ``tail'' refers to:
    \begin{itemize}
        \item The probability that a random variable takes \textbf{very large or very small values}
    \end{itemize}
    \item Motivation question (from case study):
    \begin{itemize}
        \item \textit{How to predict worst-case demands on a server?}
    \end{itemize}
\end{itemize}

\noindent $\Rightarrow$ This motivates the need for \textbf{inequalities that bound probabilities without knowing full distributions}.
